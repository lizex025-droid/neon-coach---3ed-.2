# مصفوفة الميزات والتحقق (Feature Matrix & Verification)

توثق هذه المصفوفة كل شاشة وزر داخل تطبيق **NEON COACH**، وسلوكه الفعلي، وحالة حفظه وتخزينه، وحالة اختباره.

الحالات المعيارية:
- **implemented**: ميزة حقيقية متكاملة ومنفذة بالكامل ومحفوظة ومختبرة برمجياً.
- **demo-only**: ميزة مخصصة لمحاكاة العرض التجريبي محلياً (مثل حسابات العملاء المتعددين والرسائل المسبقة).
- **blocked**: ميزة تتطلب مفتاح خدمة خارجي مدفوع (مثل مفاتيح Gemini السحابية الحية) وتعمل حالياً عبر المحاكي الموثق.
