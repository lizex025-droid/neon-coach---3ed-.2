# NEON COACH — مدربك، خطتك، تقدمك 💚⚡

تطبيق تدريب شخصي وتغذية متطور باللغة العربية (RTL) مبني بتقنيات الويب الحديثة **Vanilla HTML5 + Modern CSS + JavaScript ES Modules** مع **Vite** كبيئة تطوير وبناء، وبدعم كامل للعمل كـ **PWA مستقل يعمل بدون إنترنت (Offline-First)**.

تم بناء التطبيق وتصميمه ليتطابق بصرياً ووظيفياً بنسبة 100% مع الشاشات المرجعية العشر لنظام **NEON COACH**.

---

## ✨ المميزات الرئيسية للنظام

1. **الهوية البصرية المتوهجة (Neon Aesthetics)**:
   - خلفية ليلية فاخرة `#020605` مع بطاقات داكنة `#07100D` ولمسات نيون خضراء متوهجة `#55F7A5`.
   - شخصية القط المدرب الرياضي (Neon Cat Mascot) وشخصية القط على الميزان في الاستبيان.
   - حلقات تقدم دائرية نيون فائقة الدقة محسوبة بنسب رياضية حقيقية.

2. **شريط التنقل الثابت (Fixed Bottom Navigation)**:
   - 5 بوابات رئيسية بالترتيب الصارم من اليمين: **اليوم**، **التغذية**، **التدريب**، **التقدم**، **حسابي**.

3. **استبيان التخصيص الكامل (7 خطوات)**:
   - حفظ تلقائي للتقدم مع إمكانية الاستئناف.
   - حساب فوري للعمر، والـ BMI، ومعدل الأيض BMR (بمعادلة Mifflin-St Jeor)، واستهلاك الطاقة TDEE.
   - تطابق حسابي صارم 100% بين السعرات والماكروز: `السعرات = (البروتين × 4) + (الكارب × 4) + (الدهون × 9)`.
   - توليد برامج تدريبية مطابقة بدقة لعدد الأيام المحددة (1 إلى 6 أيام) مع تجنب الإصابات ومراعاة المعدات.

4. **لوحة اليوم التفاعلية (Today Dashboard)**:
   - حلقة السعرات اليومية مع أشرطة البروتين والكارب والدهون.
   - بطاقة تمرين اليوم مع بدء الجلسة المباشرة.
   - بطاقة الماء (إضافة كوب، تراجع، وسلسلة الأيام المتتالية).
   - بطاقة المكملات مقسمة إلى فترتي الصباح والمساء.
   - مقياس طاقة اليوم بخمس مستويات تفاعلية.

5. **جلسة التمرين الفعالة (Live Workout Session)**:
   - مؤقت زمني حي للجلسة محسوب بـ Timestamps لضمان استمراريته بدقة حتى عند قفل الشاشة أو تصغير التطبيق.
   - جدول مجموعات فعلي يتيح تعديل الأوزان والتكرارات ومستوى الشدة RPE مع إنجاز المجموعات.
   - مؤقت راحة تنازلي تفاعلي مع شريط تقدم وتنبيه صوتي خفيف وإمكانية التخطي أو إضافة 30 ثانية.
   - زر «أشعر بألم ⚠️» لتوثيق موضع وشدة الألم وإشعار المدرب فوراً.
   - زر «إنهاء التمرين» مع توثيق الحجم التدريبي وكسر الأرقام القياسية ومنع الإنهاء المكرر.

6. **التغذية وسجل الوجبات الذكي**:
   - فصل تام بين الوجبة المخططة والوجبة المستهلكة.
   - زر «بدّل الوجبة 🔁» لتقديم بدائل متكافئة السعرات مع استبعاد مسببات الحساسية.
   - تسجيل الوجبات بالكتابة العربية، أو التسجيل الصوتي المباشر، أو رفع صورة الوجبة.
   - عرض مسودة تحليل ذكية تتيح تعديل الغرامات قبل الضغط على «تأكيد وحفظ».
   - قائمة مشتريات أسبوعية مجمعة ومصنفة تلقائياً.

7. **المتابعة الأسبوعية وتقرير التقدم (NEON Body Report)**:
   - تسجيل الوزن وتتبع النزول مقارنة بالأسبوع السابق.
   - تقييم 6 مقاييس للحالة (طاقة، جوع، توتر، نوم، تمارين، ماء).
   - رفع وتشفير صور التقدم محلياً (أمام، جانب، خلف).
   - رسم بياني Canvas نيون عالي الدقة لاتجاه الوزن وقوة تمرين Bench Press.
   - حساب نسبة القوة التقديرية e1RM بمعادلة Epley.
   - تصدير التقرير العربي إلى PDF جاهز للطباعة والمشاركة.

8. **لوحة المدرب التفاعلية (Coach Dashboard)**:
   - إمكانية التبديل الفوري بين وضع المتدرب ووضع المدرب.
   - مراجعة استبيانات ومتابعات المتدربين واعتماد الخطط بشارة «معتمدة من المدرب 🛡️».
